---

This guide walks you through creating a minimal TailorKit app, connecting it to a running host product, and previewing it live. By the end you will have a sandboxed extension rendering a host-owned component inside the host UI.

<Note>
  Your host app must already have TailorKit installed and running before you begin. If you have not set that up yet, follow the [Host Installation](/host/installation) guide first, then return here.
</Note>

<Steps>
  <Step title="Scaffold the app project">
    Create the app project with the TailorKit CLI. Run this command in the directory where you want the project folder created, replacing the host URL if your setup uses a different port or handler path.

    ```sh
    pnpm dlx @tailorkit/cli init . \
      --name hello-tailorkit \
      --host http://localhost:3000/api/tailorkit
    ```

    The CLI scaffolds a new project directory called `hello-tailorkit` with a default view, a `tailorkit.config.ts`, and a preconfigured Vite build. Change into the new directory before running any further commands.

    ```sh
    cd hello-tailorkit
    ```
  </Step>

  <Step title="Generate host bindings">
    With your host app running, fetch its current schema and generate typed bindings:

    ```sh
    pnpm generate
    ```

    This creates `src/tailorkit.gen.ts`, which contains typed view definitions, component types, action types, and theme tokens exactly as the host exposes them. Do not edit this file — it is regenerated every time you run `pnpm generate`. Re-run it whenever the host schema changes.
  </Step>

  <Step title="Implement a view">
    Open `src/views/default.tsx` and replace its contents with the following:

    ```tsx src/views/default.tsx
    import { createView } from "@tailorkit/app";
    import { Box } from "#tailorkit";

    const view = createView("/", {
      component: HomeView,
    });

    function HomeView() {
      return <Box padding="md">Hello from TailorKit!</Box>;
    }

    export default view;
    ```

    A few things to note:

    - `createView` registers this component as the handler for the `/` view that the host publishes.
    - `Box` is imported from `#tailorkit` — the generated alias that points at `src/tailorkit.gen.ts`. It is rendered by the host's own React implementation, so it uses the host product's styles automatically.
    - The generated `src/client.ts` already registers exported views, so no further wiring is needed.

    <Tip>
      The `#tailorkit` import alias resolves to your generated bindings. Every component, action, and token you use from that alias is strictly typed against the host schema.
    </Tip>
  </Step>

  <Step title="Log in and deploy">
    Authenticate the CLI with your host, then publish the first deployment:

    ```sh
    pnpm exec tailorkit login
    pnpm deploy
    ```

    On first deploy the CLI prompts you to create the TailorKit app record and writes the resulting `appId` into `tailorkit.config.ts`. Subsequent deploys update the same app. Keep `tailorkit.config.ts` committed to version control so the `appId` is not lost.
  </Step>

  <Step title="Open a preview session">
    Start a live preview session against the running host:

    ```sh
    pnpm exec tailorkit preview
    ```

    The CLI starts Vite in watch mode and prints a host preview link that looks like `http://localhost:3000/?tailorkit_preview=...`. Open that link in your browser while signed in to the host, then choose **Accept preview** in the prompt that appears.

    The app now appears in the host's normal app list and renders inside `AppView`. While the CLI is running, every successful build is uploaded in bounded chunks and the preview updates automatically. A failed build leaves the last successful preview running so you can iterate without interruption. Stop the CLI process to end the preview session immediately.

    <Warning>
      Preview sessions are tied to your local CLI process. If you close the terminal, the preview ends and the app reverts to its last published deployment for other users.
    </Warning>
  </Step>
</Steps>

You now have a sandboxed TailorKit app rendering a host-owned `Box` component inside your host product. The app runs in an isolated opaque-origin iframe — the host renders the real component; the app only provides the instruction to do so.
